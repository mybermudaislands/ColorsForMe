## Decisions

- The project is not a Git repository. Preserve the user-specified working directory instead of initializing a repository or creating a branch without permission. Keep progress in this file and preserve backups before installation.
- Existing behavior is tested using mock objects only where the WoW API cannot run outside the game. Characterization tests that pass on the unmodified baseline are expected; the test runner's deliberate failure mode confirms that a failed assertion exits nonzero.
- `Roots.lua` now owns the existing root registry and loads before `Core.lua`. A manifest test failed before the extraction and passed afterward. The existing `ExtraChrome.lua` additions still extend the shared table.
- `Settings.lua` now owns initialization of saved variables and loads before `Core.lua`. A manifest and malformed-settings test failed before the extraction and passed afterward. Mode transitions remain in `Core.lua` until their dependencies are safely separated.
- `TextureAccess.lua` now owns atlas and texture-path reads, including existing protected-call and path normalization behavior. A test for the new module and its read behavior failed before the extraction and passed afterward.
- `DecorAtlases.lua` now owns the original atlas tables and category matcher. Existing eligibility behavior and the direct minimap compass check use the same matcher. A test for module loading and matching failed before the extraction and passed afterward. The existing duplicate table key is preserved for behavior-neutral extraction.
- `DecorRules.lua` owns the existing eligibility checks; `ColorEngine.lua` owns color application and restoration; `Discovery.lua` owns bounded discovery and lifecycle callbacks; and `Settings.lua` owns the existing mode transitions. Their extraction was exercised by tests that failed before the relevant module was added and passed afterward.
- A reference comparison against the original installed addon reported identical root registrations and 1,044 matching atlas/category/structural eligibility comparisons. This comparison does not prove equivalent rendering or cover every possible texture path.
- Backup: `ColorsForMe-installed-backup-2026-11-13/`, outside the game's active addon directory. Every original file was checked against the backup by SHA-256. Runtime files in the refactoring candidate were installed and checked against source by SHA-256. SavedVariables were not touched.
- LuaHelper previously reported the known duplicate key with an outdated line number after edits. Do not assume its reported line numbers reflect the current source without checking the file.
