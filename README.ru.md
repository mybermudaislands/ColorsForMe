# ColorsForMe

Лёгкий аддон для World of Warcraft, клиент **WoW Forever** (interface 16001, движок эпохи Classic). Он перекрашивает отдельные оригинальные декоративные элементы интерфейса Blizzard (рамки, обрамление панелей действий, кольца рамок юнитов, кольцо миникарты, оформление окон и подобное). Аддон не заменяет текстуры и атласы и не перемещает, не скрывает и не меняет стиль окон. Он лишь меняет цвет известных декоративных текстур стандартными вызовами `SetDesaturation` и `SetVertexColor` и в любой момент может вернуть исходные цвета.

[English version](README.md)

## Возможности

- **Classic Gray**: обесцвечивает охваченные декоративные элементы, коричневая и бронзовая отделка становится нейтрально-серой.
- **Custom Color**: любой цвет через стандартное окно выбора цвета Blizzard. Кнопка Cancel в окне возвращает предыдущий цвет.
- **Reset**: возвращает точные исходные цвет и насыщенность всех текстур, которых коснулся аддон.
- **Gryphon/Wyvern tint relief** (только в режиме Custom Color): настройка от 0% до 150% с шагом 25%, которая осветляет грифонов и виверн на панели действий (тёмный пользовательский цвет иначе делает их слишком тёмными). В Classic Gray и Reset ничего не меняет.
- **Кнопка у миникарты**: левый клик открывает окно настроек, правый открывает выбор цвета, перетаскивание перемещает кнопку вокруг миникарты. У аддона также есть пункт в Addon Compartment.
- **Только точечное покрытие**: аддон работает с фиксированным списком известных окон Blizzard (панели действий, миникарта, рамки игрока/цели/фокуса, трекер задач, микроменю, окна счётчика урона и многие стандартные окна: персонаж, книга заклинаний, журнал заданий, торговец, обмен, почта, добыча, сумки, карта, игровое меню, друзья/социальное окно, поиск группы и другие). Перекрашиваются только отдельно опознанные декоративные текстуры. Иконки, портреты, текст, кнопки, предметы и квестовые значки не затрагиваются.
- **Малая нагрузка**: нет таймеров и постоянного опроса. Каждая текстура запоминается и красится один раз, затем используется кэш. В бою работа откладывается и выполняется после его окончания. Внешних библиотек нет.
- Настройки сохраняются на уровне аккаунта в `ColorsForMeDB` (режим, пользовательский цвет, положение кнопки у миникарты, значение для грифонов).

## Установка

1. Закройте World of Warcraft.
2. Скачайте последний `ColorsForMe-x.y.z.zip` на странице Releases этого репозитория или скопируйте папку `ColorsForMe` из репозитория.
3. Положите папку `ColorsForMe` в вашу папку AddOns (папка `Interface\AddOns` клиента WoW Forever). Должен получиться путь `...\Interface\AddOns\ColorsForMe\ColorsForMe.toc`.
4. Запустите игру и убедитесь, что ColorsForMe включён в списке аддонов.

Обновление: замените папку `ColorsForMe`. Папку `WTF` удалять не нужно, если хотите сохранить настройки.

## Команды

`/forevercolor` или `/cfm`:

| Команда | Действие |
|---|---|
| `/forevercolor` (также `options`, `config`) | Открыть или закрыть окно настроек |
| `/forevercolor classic` (также `gray`) | Режим Classic Gray |
| `/forevercolor custom` (также `color`) | Открыть выбор цвета для режима Custom Color |
| `/forevercolor reset` (также `original`) | Вернуть исходные цвета |
| `/forevercolor status` | Показать текущий режим, число затронутых слоёв текстур и ожидает ли работа конца боя |
| `/forevercolor scan` | Вручную перепроверить загруженные окна Blizzard |
| `/forevercolor probe [FrameName]` | Диагностика для разработчика: записывает кандидатов-текстуры известного окна Blizzard в `ColorsForMeDB` (только чтение, только вне боя). После запуска сделайте `/reload`, чтобы данные записались на диск |
| `/forevercolor inspect` | Диагностика для разработчика: выводит цепочку родительских фреймов и атлас/путь текстуры под курсором (только вне боя) |

## Известные ограничения

- Аддон написан для WoW Forever (interface 16001). Названия части окон Forever не подтверждены в живом клиенте. Если окно не перекрасилось, его декоративный слой пока не распознан. Правила «красить все текстуры окна» в аддоне намеренно нет.
- Используются только цветовые множители, поэтому тёмно-коричневый фон не всегда можно сделать идеально нейтрально-серым без замены исходной текстуры.
- В бою перекраска не выполняется. Она ставится в очередь и применяется после боя.
- Окна, которые клиент помечает как запрещённые для аддонов (например, некоторые окна магазина), пропускаются.
- Текстовые документы внутри папки аддона (`README_RU.txt`, `CHANGELOG_RU.txt`, `PERFORMANCE_AUDIT_RU.txt`) написаны по-русски. `README_RU.txt` и `CHANGELOG_RU.txt` описывают текущую версию, а `PERFORMANCE_AUDIT_RU.txt` это исторический аудит версии 0.3.2.

## Разработка

Тесты используют имитацию API WoW и запускаются обычным интерпретатором Lua 5.1 из корня репозитория: `lua5.1 tests/run.lua`. Это характеризационные тесты, а не доказательство работы в игре.
