# Changelog

All notable changes to this project are documented in this file. The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.4.6] - 2026-11-22

### Changed

- Added the MIT license (`LICENSE`) and a License section in the README files.
- Set the author to mybermudaislands in the toc, Lua header comment and Russian README.
- Updated documentation. No change to addon behavior.

## [0.4.5] - 2026-11-22

### Added

- Initial public release.
- Classic Gray, Custom Color (Blizzard color picker) and Reset modes that recolor selected original Blizzard decorative UI art without replacing any texture.
- Targeted coverage of action bars, minimap, unit frames, objective tracker, micro menu, damage meter windows, game menu, social/friends window, trade window and many standard Blizzard windows.
- Gryphon/Wyvern tint relief setting (0% to 150%, 25% steps) for Custom Color mode.
- Settings window, minimap button and Addon Compartment entry.
- Slash commands `/forevercolor` and `/cfm` (`classic`, `custom`, `reset`, `status`, `scan`, `probe`, `inspect`).
- Combat deferral, per-texture caching and no timers or polling.
- Design, plan and progress documents (`docs/`, `reports/`, `ColorsForMe-Design.md`, `NEXT-CHAT-PROMPT.md`) with local paths replaced by placeholders.

### Changed

- Aligned version references (Russian README, Lua file header comments) with the toc version 0.4.5. No change to addon behavior.
